# ThirdHub v4 —— 项目完整介绍

> 版本: v4.0.0-m2 | 定位: 全平台智能聚合站 | 一句话: **一个入口，所有娱乐**

## 一、这是什么

把小说/漫画/视频/音乐/直播聚合进**一个软件**的平台：
你在手机/电脑/平板上打开 ThirdHub 前端（纯播放器），搜索一次，
书、漫、影、音四类结果同时出现——点哪个看哪个。
内容不是 ThirdHub 自己的，而是来自你局域网里运行的**开源引擎**
（开源阅读 Legado 等官方原版，零改动）和后端内置的四大沙箱引擎。
数据全在你自己的设备上（数据主权），账号体系轻量化（全功能免费）。

## 二、核心理念（六铁律）

1. **前端=纯播放器**：零源规则、零解析逻辑——法律边界清晰，一切规则都在引擎里
2. **能力路由**：前端只说"我要搜小说"，后端按引擎广播的能力(caps)自动派发
3. **引擎零改动**：开源引擎官方原样运行（Legado 开官方 Web 服务即可接入），后端只做调用和结果转译
4. **全模块化**：前端无"首页"，悬浮球导航七大板块；新模块=建目录+注册一行
5. **数据主权**：用户内容数据全在用户自己的后端；云端配额仅 1MB/用户（头像<0.5MB+设置同步）
6. **插件零配置**：装官方引擎→开一次服务→后端自动发现配对；用户唯一手动动作=导入书源

## 四、功能全景

**内容四链路**（全部可用，带聚合搜索/进度记忆/源管理）：
- 📖 小说：Legado 原版引擎优先（官方规则100%兼容）+内置引擎兜底（链式/XPath/JSONPath/POST/翻页/净化）
- 🎨 漫画：Venera 图源沙箱，画廊阅读器+翻话预加载
- 🎬 视频：drpy 沙箱（数百现成源一键导入），选集/线路/真实播放+直播板块
- 🎵 音乐：MusicFree 音源沙箱，歌单/播放/歌词

**系统功能**：应用锁(PIN)/首启引导/Web控制台(浏览器管理四类源+搜索测试)/引擎管理台(谁在线/什么能力)/下载管理(aria2)/相册同步(压缩上传)/网盘(Cloudreve)/密钥库(AES加密)/i18n(前后端7语即时切换)/设置中心(网页版"我的"全功能复制)/1MB云配额多端同步骨架/阅读进度存后端

## 九、为什么是这套架构

传统聚合站死在两件事：源规则的法律风险和引擎兼容的维护地狱。
ThirdHub 的解法是结构性回避——规则在用户的引擎里（Legado 官方版，法律责任归用户本地使用），
引擎永远官方更新（零改动零适配），后端只做能力路由和数据搬运。
1MB 云配额让用户数据主权可感知，全功能免费让增长先于商业化。
