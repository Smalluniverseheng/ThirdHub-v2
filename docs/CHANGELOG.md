## 第 4 代（四代 · ThirdHub v4）

> **自 4.25.0 起，完整更新历史不再随安装包下发**，改为点开应用内「更新历史」时从云端按需拉取
> （数据表 `th_changelog`，分公开段与管理员段，分级由服务端 RLS 强制）。

### v4.26.0　2026-09-19　🔴 关键修复

- **修复「连上了却一直显示未连接引擎 + 搜索什么都搜不到」（根因）**：应用未声明允许明文 HTTP，而引擎是本机/局域网里的 `http://` 服务，在较新系统上所有请求都被系统层拦掉，界面却只说「未连接」、不说原因。现已放开局域网明文并给出细化策略，同时把失败原因（明文被拦 / 引擎没开 / 网络不通 / 地址解析失败）如实显示出来
- **连接状态改为实时**：状态不再等页面重绘才更新，连上/断开立刻反映；启动探测更宽容，不会再因为一次慢响应就把已经存好的连接清掉
- **搜索改为「持续瀑布流」**：先快速出首屏，触底或点「加载更多」继续往下取，翻页不重扫、秒回；顶部实时显示「已返回 N 条 / 引擎共 M 条」与扫描是否被时间预算截断
- **一次搜索拿全部类型**：以前按类型逐个请求等于把同一份全源扫描做 4 遍；现在一次请求返回全部类型并按模块分组
- **按类型搜索更快**：首屏用更小的扫描预算先出结果，要更多时再加深扫描
- **发现页不再点进去就报错**：过滤掉没有可用地址的分类标签（旧版会显示出点了必然失败的标签）
- 底部导航与模块面板：模块面板可继续向上拖动查看更多模块；长按模块进入自由拖动排序（桌面式布局）；模块间左右滑动改为可关闭的直接跳转，不再「从几个模块中间穿过去」导致无谓加载

### v4.25.0　2026-09-18　🟡 重大更新

- 底部导航全面重做：整条改为一块微微凸起的面（顶边高光 / 底边暗影），选中项「陷进去」而不是换背景色，与全应用拟态风格统一；模块少时等分铺满，模块多时横向自由滑动，「我的」固定最右
- 切换手感重做：去掉会与切页动画打架的回跳兜底，改为带缓动的翻页过渡 + 选中项弹性缩放 + 触感反馈；新增「左右滑动切换模块」开关（默认开，可在「我的 → 导航」关闭）
- 更新历史按需加载：不再打进安装包，点开时才拉取；支持逐版本折叠展开、下拉刷新、本地缓存（离线可看）
- 更新历史分级可见：普通账号只看 4.0 之后的记录，管理员账号可切到全部历史
- 本地播放器补齐格式与能力：本地视频支持外挂字幕（srt / vtt / ass，自动识别同目录同名文件）、倍速、断点续播、横屏全屏、双击左右快进退；系统解码器不支持的封装给出可读提示并可交给系统播放器打开。本地小说新增 fb2 / html / htm / xhtml / rtf；音视频与漫画的可导入格式一并扩充
- 导入结果可视化：不再只提示「未导入」，改为逐条给出失败原因
- 隐私政策更正：如实披露可选账号体系与同步范围，统一内容源表述
