## 架构总原则
| 原则 | 状态 | 说明 |
|---|---|---|
| 前端 = 纯播放器，无任何源/规则残留 | ✅ | v4.4 移除源管理页、源名展示、源统计；模块内无「源」标签 |
| 书源/规则管理只在引擎与后端 | ✅ | 前端不出现书源概念；源导入只在引擎(阅读引擎App)与后端API |
| 后端 = 纯资源库(存储+引擎调度)，不预设任何规则 | ✅ | data/library 存书；搜索=引擎∪本地库 |
| 引擎匿名、无鉴权、与后端外观解耦 | ✅ | THP 协议明文广播，第三方可独立实现 |
| 通用协议 THP 开源，写在后端包内 | ✅ | docs/THP.md 随仓库与安装包分发 |
