## 一、后端功能详单(server/)

### 1. 网关与安全
| 功能 | 状态 | 说明 |
|---|---|---|
| HTTPS 自签 TLS | ✅ | 首启自动生成证书+SHA256指纹(TOFU) |
| 共享密钥鉴权 | ✅ | thsec_ 密钥, 全端点校验(除meta/pair) |
| 加密信封 | ◐ | sealbox-v1 协议设计在, 共享密钥模式已用, 完整密钥交换二期 |
| CORS | ✅ | 预检+放行(局域网) |
| 请求限流 | ✅ | 搜索并发池 max6 + 单源串行 |
| 启动自检 | ✅ | 版本/证书/依赖/引擎/源数横幅 |

### 2. 书源引擎(小说)
| 功能 | 状态 | 说明 |

| 正文翻页 | ✅ | nextContentUrl 拼接(修半章) |
| 正文净化 | ✅ | script/广告标签移除+垃圾行过滤 |
| 图片章节 | ✅ | images数组(前端Gallery渲染) |
| 书源自定义header | ✅ | JSON或多行K:V(覆盖UA) |

## 三、一句话总结
后端=四引擎+能力路由+存储同步+控制台的完整家庭服务器;
前端=纯播放器+悬浮球导航+设置中心的新拟物跨端壳;
两者间只有 IR 和"我要什么类型"的语义, 没有任何源规则跨界。
