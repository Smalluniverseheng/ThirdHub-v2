# 第三方后端容器（可选增强）

## 两种用户，一套 App

| | 普通版（无后端） | 进阶版（有后端） |
|---|---|---|
| 浏览 / 搜索 / 排行 / 直播 / 番剧 | 前端直连，可用 | 可用 |
| 播放 / 弹幕 / 评论 | 前端直连，可用 | 可用 |
| B站扫码登录 / 1080P / 收藏夹 / UP 主页 | 前端完成，可用 | 可用，**不用再登录一次** |
| 红果短剧 | 前端缓存为主，离线可看 | 在线刷新更及时 |
| 下载到 NAS / 资料库同步 / 后端管理 | 不需要 | 可用 |

**后端不是前置条件**：没跑这个容器，App 的所有前端能力照常工作。

## 一次登录，前端授权给后端

1. App 里「视频 → 哔哩哔哩」顶部扫码登录（cookie 只存手机本机）。
2. App 连上后端后自动调用 `POST /v1/auth/delegate`，把登录态委托过去。
3. 后端把 cookie 存在容器 `/data/delegated-auth.json`（权限 0600），
   之后 `/v1/bili/*` 直接复用，状态接口返回 `delegated: true`。
4. App 退出 B站登录时调用 `DELETE /v1/auth/delegate` 撤销；容器重启后自动恢复。

公开令牌不能调用委托接口，只有配对主密钥可以。cookie 不进日志、不随公开接口返回。

## 启动

```bash
cd deploy/standalone
docker compose up -d
docker compose ps
```

App「我的 → 连接后端」填 `https://<主机IP>:9527`，用控制台里显示的配对密钥完成连接。
自签证书第一次需要点「继续访问」（App 内走 TOFU 信任）。

## 拆分 / 一体

- **拆分（当前形态）**：App 是完整前端，后端是独立容器；适合大多数人。
- **一体（进阶）**：App 内已支持把 AI 整套装进手机（本机数据包），
  但完整 Node 后端容器尚未内置进 APK —— 这一步按需再做，不影响上面的拆分形态。
