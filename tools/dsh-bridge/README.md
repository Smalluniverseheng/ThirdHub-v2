# DSH ⟷ ThirdHub 桥接

把电脑上的 **DSH（DeepSeek Harness）** 接进 ThirdHub 的「端间互通」——
之后**手机 App 和电脑登录同一个账号，就会自动互相发现**，手机端一键连上电脑的 DSH。

## 为什么不用扫码/配对码

社区现有的 DSH 远程方案（dsh-remote 各家）大多走「二维码 + 网关 + 公网隧道」。
本方案走**账号级自动配对**：

```
        ┌──────────────────────────────┐
        │  中枢（ThirdHub 后端 :9527）   │
        │  同一账号下的所有端汇进一张表   │
        └───────┬──────────────┬───────┘
                │ ①注册+心跳     │ ②拉端列表
        ┌───────┴──────┐  ┌────┴─────────┐
        │ 电脑：本脚本   │  │ 手机：ThirdHub │
        │ + 本机 DSH    │◄─┤ App（同账号）  │
        └──────────────┘  └──────────────┘
                ③局域网直连（无需公网、无需隧道）
```

- **不需要**公网 IP、不需要 Cloudflare 隧道、不需要扫码；
- 数据不出局域网（中枢本身也是你自己的后端）；
- 电脑重启后重新跑本脚本即恢复。

## 用法

```bash
# 电脑上（Node 18+，零依赖）
node dsh-bridge.cjs \
  --hub http://127.0.0.1:9527 \
  --account 你的账号 \
  --password 你的密码 \
  --name 我的电脑 \
  --dsh http://127.0.0.1:3080
```

| 参数 | 说明 |
| --- | --- |
| `--hub` | 中枢地址 = ThirdHub 后端（同机时 `http://127.0.0.1:9527`） |
| `--account` / `--password` | **与手机 App 登录的同一账号** —— 自动配对的关键 |
| `--name` | 显示在手机端设备列表里的名字（默认取主机名） |
| `--dsh` | 本机 DSH 地址（默认 `http://127.0.0.1:3080`） |
| `--url` | 手机直连用的局域网地址（默认自动探测 `本机IP:DSH端口`） |

跑起来后会每 30 秒心跳一次；断网/中枢重启会自动重连。

## 手机上怎么用

1. 手机 App 用**同一账号**登录；
2. 打开「设备」页（端间互通）——电脑会自动出现在**在线**分组里（能力显示 `dsh`）；
3. App 的 AI 面板里点「连接电脑」，或让 AI 自动配对 —— 之后所有 AI 会话都跑在电脑的 DSH 上。

## 开机自启（Windows）

「任务计划程序」→ 新建任务 → 触发器选「登录时」→ 操作：

```
程序:   <node.exe 完整路径>
参数:   "<本脚本完整路径>" --hub http://127.0.0.1:9527 --account 你的账号 --password 你的密码
起始于: <本脚本所在目录>
```

## 排查

| 现象 | 检查 |
| --- | --- |
| `[join] 失败 HTTP 0/超时` | 中枢地址对不对、后端是否在跑（浏览器开 `http://127.0.0.1:9527/api/v1/health`） |
| 手机端看不到电脑 | 两边**账号是否一致**；电脑端是否显示 `在线端≥2` |
| 连上了但 AI 无响应 | 电脑本机开浏览器访问 `http://127.0.0.1:3080` 确认 DSH 本身可用 |
| 局域网 IP 探测错了 | 用 `--url http://正确的IP:3080` 手动指定 |
