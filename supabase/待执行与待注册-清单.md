### 为什么这些一直没执行？
这些 SQL 写在网页端仓库（`D:/ai/deep seek/supabase/`），而 Supabase 是云端库；
service_role 密钥**不能执行 DDL**（实测：PostgREST 对 DDL 一律 PGRST202/404）。
→ 只能由人在 SQL Editor 执行，或提供**数据库连接串**自动执行。

### 如果以后要"自动建表"
需要以下任一（用户提供后即可自动化）：
- **数据库连接串**：Supabase → Settings → Database → Connection string（`postgresql://postgres:***@...`），有它就能用 psql/node-pg 直接跑 DDL；
- 或 **Management API Token**：Supabase → Account → Access Tokens（`sbp_...`）。
